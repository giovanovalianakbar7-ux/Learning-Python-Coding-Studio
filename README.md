## Cara menggunakan
- Notebook (.ipynb): buka di VS Code / Jupyter Notebook dan jalankan cell per cell.
  - Contoh: buka [test.ipynb](test.ipynb) atau [Kodingan hpp.ipynb](Kodingan%20hpp.ipynb).
- Script Python (.py): jalankan via terminal:
  - python "sesi 2/sesi 2.py"
  - python "sesi 1/button.py"
- File teks/HTML: buka langsung di editor atau browser:
  - [test.html](test.html)
  - [sesi 1/random.txt](sesi%201/random.txt)

## Tips & langkah selanjutnya
- Tambahkan virtual environment dan requirements.txt jika perlu dependency.
- Konversi eksperimen penting menjadi modul terpisah untuk latihan pengujian.
- Buat proyek kecil (mis. toko mini, chatbot, kalkulator biaya produksi dari `Kodingan hpp.ipynb`) untuk menerapkan materi.
